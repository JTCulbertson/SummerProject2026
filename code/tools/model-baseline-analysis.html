Model Baseline Analysis

Measure a vision model's puzzle capability three ways — blind solve, reconstruct, and reconstruct-then-solve — score each against ground truth, and log the results. Accepts both MARC (single masked test output) and NARC (narrative sequence, one or more masked frames) puzzles; the puzzle kind is auto-detected from the JSON and the model is prompted accordingly.

1. MindRouter Connection

First time? Browsers can't call MindRouter directly (it sends no CORS header, so fetch fails with a “NetworkError”). Start the bundled local proxy once, in a terminal:
uv run code/scripts/cors_proxy.py
then keep the Base URL as http://localhost:8811/v1. The proxy injects your key from keys.txt, so you can leave the API Key field blank. Open this page locally (or via python3 -m http.server in site/).
Config is saved in your browser. The dropdown is populated live from GET {base}/models.

2. Puzzle

The puzzle is rendered to an image in-browser (ARC palette + legend, masked cells hidden as “?”) — exactly what the model sees. The file also supplies the ground-truth answer(s) used for scoring. MARC vs NARC is auto-detected (NARC = schema: "narc-export-v1" / a sequence array).

3. Batch Sweep — NARC only

Runs the same three experiments over every puzzle × every model, appending one JSON line per experiment straight to disk. Scoring is not done here — feed the results file to uv run code/scripts/narc_score.py, which is the single place metrics are computed, so a batch run from this page and one from run_narc_sweep.py are graded by identical code.
Pick a puzzle folder to build the queue. Using the image folder makes every request byte-identical to the Python sweep; without it, images are rendered here instead.

4. Run the Three Experiments — single puzzle

1 · Blind solve — image → test output grid, no reconstruction.
2 · Reconstruct — image → JSON, scored on visible cells (train grids + test input).
3 · Reconstruct-then-solve — reuse the reconstruction, then solve from that JSON (text only).
