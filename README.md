# SummerProject2026

Summer 2026 research project by JT Culbertson.

## Structure

| Directory | Contents |
|-----------|----------|
| `papers/` | Lab notebook (LaTeX source + PDF) and reference papers |
| `site/` | Plain HTML/CSS/JS site, auto-deployed to [GitHub Pages](https://jtculbertson.github.io/SummerProject2026/) |
| `code/` | Project source code |

## GitHub Pages

The site deploys automatically from `site/` on every push to `main`.

**One-time setup:** Go to **Settings → Pages → Build and deployment → Source** and select **"GitHub Actions"**.
