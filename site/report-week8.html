Week 8 — Reading the Story: NARC Joins the Baseline Tool

Week 8 July 20, 2026 ToolsResearch

The Week 6 baseline tool could only measure one puzzle family — MARC, where a single hidden answer is inferred from example pairs. This week it learned a second: NARC, where a short story is told across an ordered sequence of grids and one or more frames are blanked out. The same three experiments now run on both, and — after a NARC "solve" that looked too good to be true — we added the controls needed to tell a real result from an easy one.

View the baseline tool on GitHub →

In Plain Terms

A MARC puzzle gives the AI a few before-and-after examples and asks it to fill in one missing answer. A NARC puzzle is different: it's a little comic strip. Several grids in a row show a scene changing step by step — a game of Stump, say — with a written story describing what happens, and one panel is hidden behind a "?". The AI has to figure out the missing panel from the story and the panels around it. This week our measuring tool learned to read those comic strips too. Then something surprising happened: on the very first try, a model got a hidden panel exactly right — even though the same models struggle badly with MARC. Before celebrating, we checked why, and the honest answer is less exciting than it looked. So we also built switches to make the test fair.

Why Now

Weeks 3–6 built a consistent picture of how models read MARC puzzles: shape almost perfectly, color only partially. NARC puzzles stress a different muscle — following an ordered sequence and tying it to a narrative — so bringing them onto the same measuring bench lets us compare the two kinds of reasoning with one consistent scoring pipeline instead of two separate ones.

The trigger was practical, too: NARC puzzles were being authored and visualized, but there was no way to put a model in front of them and score it. Extending the Week 6 tool — rather than writing a new one — means every NARC run is measured exactly like a MARC run, and lands in the same log.

What Changed in the Tool

The baseline tool now accepts both puzzle families and adapts to whichever it's given. It reads the JSON, figures out the kind, and prompts the model accordingly — no mode switch to remember.

Auto-detects MARC vs. NARC

A NARC file (schema narc-export-v1, a sequence of frames plus a narrative) is recognized automatically and rendered as an ordered strip — frames left-to-right with arrows between them, and each masked frame drawn as a "?". MARC files behave exactly as before.

NARC-aware prompting

The model is told this is a narrative sequence, that the order of frames is the story, and that there may be more than one masked frame — each identified by its position. It runs the same three experiments as MARC: blind solve, reconstruct, and reconstruct-then-solve.

Per-frame scoring

Every masked frame is scored against ground truth; a run counts as "solved" only if all masked frames match exactly, with per-frame cell accuracy shown alongside.

Image override

The rendered image is always generated from the JSON, but you can now upload a custom image in its place while keeping the same JSON, prompts, and ground-truth scoring — so alternate representations (including the Week 7 greyscale encodings) can be tested head-to-head on identical scoring.

Full prompt captured in the log

Each experiment now records the exact prompt text that was sent, viewable in the run's details for later review — so it's always clear what the model actually saw.

A rendering bug was also fixed along the way: the diagonal shading on masked frames was bleeding over neighboring grids, which could have interfered with how a model read the image.

The Result That Started It

On the first NARC test, a model blind-solved a hidden frame exactly — a sharp contrast with how much these same models struggle to even reconstruct MARC grids. Tempting to call it a breakthrough. It isn't, and the numbers say why. A NARC masked frame is usually a near-copy of the frame just before it:

The Ghost of the Tortoise2592%2
Stump15087%20

The tortoise frame is the previous frame with two cells changed — and the narrative describes which two. That's "copy the last panel, apply a narrated tweak," not the abstract rule-induction MARC demands. Add that the written story can hand over the answer in plain language, and an exact solve says more about low edit-distance plus a language shortcut than about a model suddenly reading grids well. One easy puzzle is an anecdote, not a finding.

Making the Test Fair

To separate "NARC is genuinely easier" from "the extras gave it away," the tool now exposes what the model is told besides the image, as two switches:

  • Include the narrative — off means the model solves from the frames alone. If accuracy collapses without the story, it was leaning on language, not pixels.
  • Include masked-frame grid sizes — off means the model has to infer the output shape, putting NARC on the same footing as MARC blind-solve, which never gets a size hint.

Both default on (preserving prior behavior), both are recorded per run, and each run's card shows which were active — so a run's score can never be misread as more (or less) impressive than the inputs it was given.

How to Use It

  1. Open code/tools/model-baseline-analysis.html locally and start the bundled proxy (uv run code/scripts/cors_proxy.py) so the browser can reach MindRouter.
  2. Pick a model, then load a puzzle — a MARC file from code/puzzles/ or a NARC file from code/narc_puzzles/. The kind is detected for you.
  3. For NARC, choose whether to include the narrative and the grid sizes, or leave both on.
  4. Optionally override the image to test an alternate representation on the same scoring.
  5. Run the three experiments, then open a run's details to inspect per-frame grids, the exact prompt sent, and the model's reasoning.

Next Steps

With NARC on the bench and fair controls in place, the plan is to run the narrative-on / narrative-off comparison across several puzzles and models to quantify how much models lean on the story versus the grids — and to fold in the Week 7 greyscale encodings via the image override, testing whether a color-free representation changes the picture on sequences too. A copy-the-previous-frame baseline is the natural yardstick to report every NARC score against.
